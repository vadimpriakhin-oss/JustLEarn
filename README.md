# JustLEarn

An interactive learning app with multiple quiz modes: True/False, Multiple Choice, Fill in the Blank, and Drag & Drop.

## Features

- Multiple quiz modes for effective learning
- Create and manage your own terms
- Works offline as a Progressive Web App (PWA)
- Installable on Android, iOS, and Desktop

## Install as PWA

### Android / Desktop (Chrome, Edge)
1. Open the app URL in your browser
2. Look for the **Install** button in the address bar (or browser menu)
3. Tap **Install** and the app will be added to your home screen / desktop

### iPhone / iPad (Safari)
1. Open the app URL in Safari
2. Tap the **Share** button (box with arrow)
3. Scroll down and tap **Add to Home Screen**
4. Tap **Add** to confirm

## Deploy to Vercel

### One-click deploy
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/vadimpriakhin-oss/JustLEarn)

### Manual deploy
1. Go to [vercel.com](https://vercel.com) and sign in
2. Click **New Project** and import the `vadimpriakhin-oss/JustLEarn` repository
3. Vercel will auto-detect the static site settings — click **Deploy**
4. Your app will be available at `https://your-project.vercel.app`

## Run Locally

```bash
npm install
npm start
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.
