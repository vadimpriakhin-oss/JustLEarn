# JustLEarn

A flashcard quiz app — learn vocabulary your way.

## Features

- True / False, Multiple Choice, Fill in the Blank, Drag & Drop quiz modes
- Add custom terms
- **Progressive Web App** — install on iOS and Android without an App Store

## Installing on your device

See [INSTALL.md](INSTALL.md) for step-by-step instructions to add JustLEarn to your Home Screen on iOS (Safari) or Android (Chrome).

## Offline support

After the first visit all assets are cached by the Service Worker, so the app works without an internet connection.
